# Color

## Solves

Use color to encode meaning or direct attention without creating a second, accidental message.

## Ask first when needed

If color already has domain meaning, preserve it unless the user explicitly wants a remapping.

## Encoding

- nominal categories → a categorical palette;
- ordered or continuous magnitude → a sequential palette;
- deviation around a meaningful center → a diverging palette;
- focus versus context → one restrained highlight role plus muted context.

Do not use a diverging palette merely because two colors look attractive.

## Guardrails

- essential distinctions should remain interpretable without color alone when feasible;
- avoid rainbow palettes for ordered quantitative values;
- provide a legend or colorbar when the mapping is not obvious;
- keep missing or invalid values visually distinct from valid low values;
- reserve strong accent colors for actual emphasis.

Exact hex values belong to a project theme, not to this ingredient.
