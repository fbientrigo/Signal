# Chart selection — compact reference

Start from the reader question, not a chart menu.

Use this table as routing guidance, not as a whitelist.

| Reader problem | First recipe / path | Main caveat |
|---|---|---|
| Understand one numeric distribution | `distribution_overview` | histogram bins change appearance |
| Understand relationship between numeric variables | `relationship_overview` | overplotting may hide structure |
| Compare category magnitudes | `categorical_comparison` | bars encode length from zero |
| Follow an estimate across ordered x with uncertainty | `trend_with_uncertainty` | know what the interval means |
| Keep one subset prominent without losing context | `focus_in_context` | emphasis must not erase context |
| Ranking, before/after, composition, unusual scientific views | compose ingredients | do not force an ill-fitting recipe |

## Familiar encodings first

When practical, prefer position on a shared scale over area, angle, volume, or decorative shape.

Use familiar representations unless a less common one materially reduces decoding effort.

## When the choice is unclear

Ask the smallest question that would change the representation.

Examples:

- Is the main goal shape or comparison?
- Is x genuinely ordered?
- Does color already have semantic meaning?
- Should the background remain visible as context?

If no existing recipe fits after the answer, compose ingredients directly.
