# Layout and small multiples

## Solves

Arrange comparable views so the reader can compare without excessive overlap or legend decoding.

## Small multiples

Use facets when the same question is repeated across groups and overlay would become crowded.

Prefer:

- consistent axes when direct comparison matters;
- repeated visual grammar across panels;
- shared labels and restrained titles;
- enough panel size to keep marks and uncertainty legible.

Allow different scales only when that choice is necessary and explicitly useful.

## Context inside panels

A useful composition is:

```text
all data as muted context
+ panel-specific subset as focus
```

when the reader needs both local detail and the common frame of reference.

## Guardrails

Do not facet merely because a categorical variable exists.

If the panels no longer fit the destination at readable size, reduce the comparison or choose another structure.
