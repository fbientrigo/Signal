# Focus in context

## Use when

The reader must notice one subset, benchmark, candidate, or region while still seeing the evidence around it.

This is intentionally a flexible recipe: the underlying visual may be a relationship, trend, distribution, categorical comparison, or another appropriate ingredient composition.

## Default composition

```text
appropriate base ingredient(s)
+ all relevant data as quiet context
+ focus redrawn with stronger emphasis
+ direct label only when useful
```

## Ask only if material

Clarify:

- what is the focus?
- what must remain as context?
- what can be removed as noise?
- does color already carry domain meaning?

## Adapt

Use color, opacity, line weight, marker shape, annotation, or reference regions according to the existing semantics.

## Avoid

Do not erase inconvenient context to make the focus look stronger.

Do not create multiple competing highlights.
