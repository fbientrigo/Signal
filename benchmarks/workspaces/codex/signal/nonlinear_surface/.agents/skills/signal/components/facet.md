# Facet / small multiples

Use facets when several groups share the same visual question but overlap would destroy readability.

Rules:

- share axes when direct comparison is the goal;
- keep ordering consistent;
- prefer direct panel titles over repeated legends;
- do not facet a tiny dataset merely to decorate the page.
