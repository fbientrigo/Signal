# Interaction

Add interaction only if it changes what the user can investigate.

Good uses:

- hover to identify dense points;
- zoom in multiscale data;
- toggle a small number of meaningful groups;
- filter a parameter range during exploration.

Bad uses:

- dropdowns compensating for an overcrowded chart;
- hover as the only place units/uncertainty are explained;
- animation with no analytic purpose.
