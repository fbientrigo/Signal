# Agent instructions

Signal is intentionally small. Protect that property.

Before changing the repository:

1. Read `CONTRACT.md`.
2. Identify the real reader problem or repeated visual decision.
3. Prefer one small vertical slice over framework work.
4. Reuse existing recipes and ingredients before adding new knowledge.
5. Use a recipe for common tasks; compose ingredients directly for unusual tasks.
6. Do not create a recipe merely to name a one-off ingredient combination.
7. Do not create ingredients for low-level plotting parameters.
8. Keep generated examples native Matplotlib, Seaborn, or Plotly.
9. Do not make target plots depend on Signal at runtime.
10. If scientific semantics matter, make them explicit.
11. If visual output changes, inspect it at its intended destination size.
12. Stop when the stated problem is solved.
