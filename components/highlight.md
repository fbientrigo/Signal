# Highlight

Use emphasis to answer "where should the reader look?" while keeping enough context to judge it.

Preferred pattern:

1. draw context in a muted semantic color;
2. re-draw the selected subset/series with the highlight color;
3. use direct annotation only when it reduces decoding effort.

Do not encode an additional scientific category accidentally through a purely decorative highlight.
