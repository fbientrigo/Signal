# Intents

Intent describes what the reader should be able to understand. It is not a chart type.

Start with a small vocabulary:

| Intent | Reader task | Typical candidates |
|---|---|---|
| distribution | understand shape, spread, tails, modes | histogram, ECDF, box/violin when appropriate |
| comparison | compare values or groups | dot, bar, grouped points, small multiples |
| relationship | understand association between variables | scatter, hexbin, contours |
| change | understand evolution or before/after difference | line, slope, paired points |
| ranking | understand ordered magnitude | dot, bar, slope when rank changes |
| composition | understand parts of a whole | stacked marks only when part-to-whole is the actual question |

Do not expand this vocabulary until a recurring question cannot be expressed clearly with it.
